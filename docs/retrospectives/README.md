# Retrospectives

One file per retrospective: `<YYYY-MM-DD>-<short-slug>.md`, from
`docs/templates/retrospective-template.md`.

Phase 7 (Validation) produces retrospective input in its validation report. When you hold the
retrospective, that input becomes a file here, with a disposition for every item: what shipped,
where, and what is still open. Items that change the workflow itself belong in `WORKFLOW.md`,
`CLAUDE.md`, or a template, not only in this folder.

A finding without a disposition is not finished.
